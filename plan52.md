### 1.1 MemGPT (OSDI 2024) - 层级记忆管理

| 信息 | 详情 |
|------|------|
| 论文 | MemGPT: Towards AI Agents with Long-Term Memory |
| 来源 | OSDI 2024 |
| 机构 | UC Berkeley, INRIA, Microsoft |
| 引用 | 500+ |
| GitHub | 5k+ Stars |

**核心机制**:
- 🔄 层级记忆管理: 工作记忆 → 核心记忆 → 外部存储
- 🔄 受限注意力窗口的智能管理
- 🔄 智能记忆检索和遗忘
- 🔄 像操作系统一样管理记忆层次

**架构图**:
```
┌─────────────────────────────────────────┐
│         受限注意力窗口 (LLM Context)      │
│  ┌───────────────────────────────────┐  │
│  │  Working Memory (短期)             │  │
│  │  - 当前对话上下文                   │  │
│  │  - 活跃实体                        │  │
│  └───────────────────────────────────┘  │
│           ↑ ↓ 智能检索                  │
│  ┌───────────────────────────────────┐  │
│  │  Core Memory (核心)                │  │
│  │  - 重要事实                         │  │
│  │  - 人物画像                         │  │
│  └───────────────────────────────────┘  │
│           ↑ ↓ 自动归档                  │
│  ┌───────────────────────────────────┐  │
│  │  External Storage (外部存储)        │  │
│  │  - 历史对话                         │  │
│  │  - 知识库                           │  │
│  └───────────────────────────────────┘  │
└─────────────────────────────────────────┘
```

**启发**:
- ✅ 层级抽象: 引入 3 层记忆管理
- ✅ 智能检索: 基于重要性的记忆提取
- ✅ 自动归档: 冷数据自动转移

### 2.2 优势与不足分析

#### 优势 ⭐

| 特性 | 评分 | 说明 |
|------|------|------|
| 认知记忆类型 | ⭐⭐⭐⭐⭐ | 8种类型 (Episodic, Semantic, Procedural等) |

| 插件系统 | ⭐⭐⭐⭐ | WASM支持 |
| 遗忘机制 | ⭐⭐⭐⭐ | Ebbinghaus曲线 |
| 记忆融合 | ⭐⭐⭐ | Consolidation |
| 多后端支持 | ⭐⭐⭐⭐ | LibSQL, PostgreSQL, LanceDB |

#### 不足 ⚠️

| 特性 | 评分 | 说明 |
|------|------|------|
| 层级抽象 | ⭐⭐ | 缺少明确的记忆层次 |
| 偏好学习 | ⭐⭐ | 用户画像较弱 |
| 实时性 | ⭐⭐ | 增量学习不足 |
| 可扩展性 | ⭐⭐⭐ | 大规模部署支持 |
| 多Agent管理 | ⭐⭐ | Agent间共享记忆弱 |
| API简洁性 | ⭐⭐⭐ | 相比Mem0较复杂 |

## 三、详细改造计划

### Phase 1: 记忆层次强化 (3周)

**目标**: 引入 MemGPT 的层级记忆概念

```
改造前:                     改造后:
┌─────────────┐            ┌─────────────┐
│ 单一记忆层   │  →         │ Working层   │ (短期记忆)
└─────────────┘            ├─────────────┤
                          │ Core层      │ (核心记忆)
                          ├─────────────┤
                          │ Archive层  │ (归档记忆)
                          └─────────────┘
```

| 任务 | 说明 | 优先级 | 工时 |
|------|------|--------|------|
| 1.1 | 引入 MemoryHierarchy trait | P0 | 3天 |
| 1.2 | 实现 WorkingMemoryManager | P0 | 5天 |
| 1.3 | 实现 CoreMemoryManager | P0 | 5天 |
| 1.4 | 实现 ArchiveMemoryManager | P1 | 3天 |
| 1.5 | 实现智能分层器 (基于重要性/频率) | P0 | 5天 |
| 1.6 | 单元测试 | P0 | 3天 |

### Phase 2: 偏好学习增强 (3周)

**目标**: 增强 Mem0 风格的用户画像

| 任务 | 说明 | 优先级 | 工时 |
|------|------|--------|------|
| 2.1 | 增强 PreferenceMemory 模块 | P0 | 5天 |
| 2.2 | 实现增量偏好提取 | P0 | 5天 |
| 2.3 | 增加用户画像 API | P1 | 4天 |
| 2.4 | 偏好记忆持久化 | P1 | 4天 |
| 2.5 | 单元测试 | P0 | 3天 |

### Phase 3: 智能遗忘优化 (2周)

**目标**: 完善 Ebbinghaus 遗忘曲线

| 任务 | 说明 | 优先级 | 工时 |
|------|------|--------|------|
| 3.1 | 引入间隔重复 (Spaced Repetition) | P0 | 5天 |
| 3.2 | 实现智能复习触发 | P0 | 5天 |
| 3.3 | 增强记忆巩固 (Consolidation) | P1 | 4天 |
| 3.4 | 单元测试 | P0 | 2天 |

### Phase 4: 可扩展性增强 (3周)

**目标**: 支持大规模部署

| 任务 | 说明 | 优先级 | 工时 |
|------|------|--------|------|
| 4.1 | 分布式记忆索引 | P2 | 7天 |
| 4.2 | 记忆分片策略 | P2 | 5天 |
| 4.3 | 高可用架构 | P2 | 5天 |
| 4.4 | 性能优化 | P1 | 5天 |

### Phase 5: API 简化 (2周)

**目标**: 对标 Mem0 的简洁API

| 任务 | 说明 | 优先级 | 工时 |
|------|------|--------|------|
| 5.1 | 简化 Memory API | P0 | 5天 |
| 5.2 | 增加统一SDK | P0 | 5天 |
| 5.3 | 文档完善 | P1 | 2天 |
